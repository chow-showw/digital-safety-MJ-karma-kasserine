## النشر على GitHub Pages

1. أنشئ حسابًا على <https://github.com/signup> إن لم يكن لديك.
2. اضغط **New repository**: اختر اسمًا (مثل `fadaa-raqmi-amin`) وحدّد **Public** (شرط النشر المجاني)، ولا تضف README.
3. في صفحة المستودع اضغط **uploading an existing file** ثم اسحب **كل الملفات** (محتويات المجلد وليس المجلد نفسه) واضغط **Commit changes**.
4. من **Settings ← Pages**: اختر **Source: Deploy from a branch**، ثم **Branch: main** و**/(root)**، ثم **Save**.
5. بعد دقيقة إلى دقيقتين يظهر الرابط: `https://اسم-حسابك.github.io/اسم-المستودع/`
6. افتح `…/qr.html` على موقعك المنشور واطبع أوراق رموز QR لتحميل الأدلة (الرموز تُبنى تلقائيًا على رابطك).
