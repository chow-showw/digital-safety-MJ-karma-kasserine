الرفع على Netlify:
1) ادخل إلى app.netlify.com ← Add new site ← Deploy manually.
2) اسحب هذا المجلد كاملًا (وليس ملف zip) إلى الصفحة، أو اختر Import from Git.
3) لا حاجة إلى أمر بناء: النشر مباشر من المجلد الجذر (publish = ".").
4) بعد كل تحديث: ارفع المجلد من جديد؛ يُحدَّث البرنامج عند الاتصال بالإنترنت لأن sw.js يفضّل الشبكة أولًا.
